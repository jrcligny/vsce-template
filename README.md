# @jrcligny/vsce-template

This is a template for creating a new VS Code extension.

This sample extension implements a custom section in the activity bar in which a tree view is displayed. This tree view contains fake data (`Element 1` to `Element 4`).

This extension also associates a command to all files at the root level. This command can be triggered using the contextual menu in the file explorer or the editor. Once the command is triggered, it displays an information message.

## Usage

Start a debugging session selecting the configuration named `Run Extension` using the Configuration dropdown in the `Run and Debug` view.

Run `npm run package` to package the extension. [esbuild]() bundles the extension based on [./tasks/build/bundle-app.mjs](./tasks/build/bundle-app.mjs) and [@vscode/vsce](https://github.com/microsoft/vscode-vsce) creates the `vsix` package. This package contains the following files:
* `app\extension.js` - generated by [./tasks/build/bundle-app.mjs](./tasks/build/bundle-app.mjs)
* `img\activity-bar-icon.svg` - from [./static/img](./static/img)
* `readme.md` - from [./static/README.md](./static/README.md)
* `LICENSE.md` - from [./LICENSE.md](./LICENSE.md)
* `changelog.md` - from [./CHANGELOG.md](./CHANGELOG.md)
* `package.json` - from [./task/build/create-package-json.mjs](./task/build/create-package-json.mjs) from [./static/package.json](./static/package.json) and [./package.json](./package.json)

Run `npm run pretest && npm run test` to launch unit tests and end-to-end tests. They use [mochajs](https://mochajs.org/).
* Unit tests
    * These tests are declared in a file ending with `.spec.ts`
    * Unit test configuration is set in [./src/spec.config.json](./src/spec.config.json)
    * Start a debugging session selecting the configuration named `Run Unit Tests` using the Configuration dropdown in the `Run and Debug` view.
* End-to-end tests
    * These tests are declared into [./test](./test)
    * Each folder represents a suite of tests using the same context. They consist of test files ending with `.test.ts` and a configuration file `test.config.json` (available options can be found in [./test/test.config.schema.json](./test/test.config.schema.json)).
    * Start a debugging session selecting the configuration named `Run e2e Tests` using the Configuration dropdown in the `Run and Debug` view. A prompt is displayed to select the configuration to execute.
